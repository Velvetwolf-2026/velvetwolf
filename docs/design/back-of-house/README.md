# Back-of-house concept references

These eight 688 x 768 WebP panels are deterministic crops of
`Gemini_Generated_Image_kopvackopvackopv.png` (2752 x 1536). They are visual
references for the procedural Three.js exhibits and are deliberately not
imported by the application or copied to `public/`.

The source sheet is a four-column, two-row grid in this order:

| Row | Column 1 | Column 2 | Column 3 | Column 4 |
| --- | --- | --- | --- | --- |
| Top | Contact | FAQ | Track Order | Size Guide |
| Bottom | Shipping | Returns | Privacy | Terms |

Runtime geometry, materials, lighting, and behavior live in
`src/velvetwolf/gallery/three/`. The panels must not be used as scene
backgrounds or textures.
